# networkwalks-B084-Wireshark-lab
I have completed a hands-on network analysis lab using Wireshark as an intern at NETWORKWALKS. For my Week 1 SOC Project, I investigated 6 live labs using Wireshark to gather evidence of cyberattacks, hidden data, passwords, and call scammers. 

The following are the tasks that I have completed for this project:
- Identified an Attacker's IP address on the network
- Practiced how to follow a TCP stream to read conversations from host to destination devices
- Found hidden usernames and passwords over HTTP
- Identified a brute-force attacker with repeated login attempts
- Identified a call scammer after investigating a recorded conversation

Experimenting with these hands-on labs was a challenge, but overall I enjoyed learning how to navigate through Wireshark and learn new skills that would be a huge help for my future career and passion in cybersecurity. 

Special thanks to Sir Waqas Karim and NETWORKWALKS for the guidance and support. Looking forward to week 2!
